# AI Agent Creation Prompt Examples

This document provides examples of effective prompts for creating AI agents using our platform. The system analyzes your prompt and automatically determines the best agent type, tools, and capabilities.

## Customer Support Agents

### Basic Support Agent
```
Create a customer support agent that can help users with common questions about our products, handle billing inquiries, and escalate complex issues to human support when needed.
```

### Technical Support Agent
```
Create a technical support agent for a software company that can troubleshoot common issues, provide step-by-step solutions, search our knowledge base, and help customers with installation problems. The agent should be patient and explain technical concepts clearly.
```

## Sales and Marketing Agents

### Sales Assistant
```
Create a sales agent that can answer product questions, provide pricing information, help customers choose the right package for their needs, and schedule demos with our sales team. The agent should be friendly and persuasive but not pushy.
```

### Lead Qualification Agent
```
Create an agent to qualify incoming leads by asking relevant questions about their business needs, budget, timeline, and decision-making process. The agent should collect contact information and score leads for our sales team.
```

## Research and Analysis Agents

### Market Research Agent
```
Create a research agent that can search the web for market trends, competitor analysis, and industry news. The agent should be able to summarize findings, identify key insights, and present information in a structured format.
```

### Data Analysis Agent
```
Create an agent that can analyze data, perform calculations, create reports, and explain statistical concepts. The agent should be able to work with numbers, identify patterns, and provide actionable insights.
```

## Educational and Training Agents

### Learning Assistant
```
Create an educational agent that can help students learn new concepts, answer questions about course material, provide study tips, and create practice quizzes. The agent should be encouraging and adapt to different learning styles.
```

### Training Agent
```
Create a corporate training agent that can onboard new employees, explain company policies, conduct safety training, and track completion of training modules. The agent should be professional and thorough.
```

## Creative and Content Agents

### Content Creator
```
Create a content creation agent that can help write blog posts, social media content, marketing copy, and email newsletters. The agent should understand brand voice, target audience, and content strategy.
```

### Creative Writing Assistant
```
Create an agent that can help with creative writing projects, provide story ideas, develop characters, suggest plot twists, and offer writing feedback. The agent should be imaginative and supportive.
```

## Specialized Task Agents

### Project Manager Agent
```
Create a project management agent that can help plan projects, create task lists, track deadlines, manage resources, and coordinate team activities. The agent should be organized and detail-oriented.
```

### Personal Assistant
```
Create a personal assistant agent that can help with scheduling, email management, travel planning, research tasks, and general productivity. The agent should be efficient and proactive.
```

### Financial Advisor Agent
```
Create a financial advisory agent that can help with budgeting, investment planning, tax questions, and financial goal setting. The agent should provide educational information and perform calculations while emphasizing that it doesn't replace professional financial advice.
```

## Multi-Agent Collaboration Examples

### Customer Service Team
```
Create a customer service agent that can handle general inquiries and collaborate with specialist agents for technical issues, billing problems, and product recommendations. The agent should know when to delegate tasks to other agents in the network.
```

### E-commerce Support Network
```
Create an order management agent that can check order status, process returns, coordinate with inventory agents for stock levels, and work with shipping agents to track deliveries. The agent should seamlessly communicate with other agents to provide complete customer service.
```

## Tips for Effective Prompts

### Be Specific About Goals
- Clearly define what the agent should accomplish
- Mention specific tasks and responsibilities
- Include target audience or user types

### Specify Desired Behavior
- Mention personality traits (friendly, professional, patient)
- Define communication style
- Set expectations for interaction quality

### Include Context
- Mention your industry or business type
- Provide relevant background information
- Explain the agent's role in your workflow

### Mention Required Capabilities
- List specific tools needed (search, calculations, etc.)
- Mention integration requirements
- Specify data sources or knowledge bases

### Examples of Keywords That Trigger Specific Features

**Reactive Agents (with tools):**
- "search the web", "perform calculations", "use tools"
- "mathematical", "computation", "API integration"

**Planning Agents:**
- "create plans", "organize steps", "workflow", "strategy"
- "project management", "process optimization"

**A2A Communication Capabilities:**
- "collaborate with other agents", "delegate tasks"
- "work with specialist agents", "coordinate activities"

## Common Prompt Patterns

### The Problem-Solution Pattern
```
I need an agent that can [PROBLEM] by [SOLUTION]. The agent should [SPECIFIC BEHAVIORS] and [INTEGRATION REQUIREMENTS].
```

### The Role-Based Pattern
```
Create a [ROLE] agent for [CONTEXT] that can [PRIMARY FUNCTIONS]. The agent should be [PERSONALITY TRAITS] and [SPECIALIZED REQUIREMENTS].
```

### The Workflow Pattern
```
Create an agent that can [STEP 1], then [STEP 2], and finally [STEP 3]. The agent should coordinate with [OTHER SYSTEMS/AGENTS] and [ADDITIONAL REQUIREMENTS].
```

Remember: The more specific and detailed your prompt, the better the system can configure your agent to meet your exact needs. Include examples of conversations or tasks when possible to help the agent understand your expectations.
